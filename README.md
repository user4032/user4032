##  About Lumyn

- Ephemeral messaging (messages disappear after reading)
- Strong **End-to-End Encryption**
- **Zero-Knowledge** system (server can't read anything)
- Real-time messaging via WebSockets
- Cross-platform (PWA + Mobile)

 [Lumyn](https://lumyn.space)

##  Tech Stack

- **Flutter / Dart**
- **Socket.IO**
