### Now

**[Lumyn](https://lumyn.space)**: a private messenger with ephemeral messages, end-to-end encryption (`X25519` + `AES-256-GCM`), a zero-knowledge server and real-time delivery over Socket.IO. Runs as a PWA, mobile app and desktop app.
